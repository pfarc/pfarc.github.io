Google Drive Integration and Data Backup

Our application (“Cüzdanım” / “Finanscık”) provides an optional cloud backup feature that allows users to securely back up and restore their financial data, including transactions, accounts, budgets, and categories.

To enable this functionality, the application requests access to the user’s Google Drive account through the Google Drive API.

How We Use Google Drive Data
The application only creates, reads, updates, and deletes a dedicated backup file named cuzdanim_backup.json within the user’s personal Google Drive.
Backup data is used solely for backup and restore operations initiated by the user.
No Access by Developers

We do not collect, store, access, or transmit users’ financial data to our own servers. All backup operations occur directly between the user’s device and Google Drive using secure encrypted connections (HTTPS).

No Third-Party Sharing

Data stored in Google Drive backups is never shared, sold, transferred, or disclosed to third parties, analytics providers, or advertisers.

Limited Google Drive Access

The application only requests the following Google Drive permission scope:

https://www.googleapis.com/auth/drive.file

This permission allows the app to access only the files it creates or manages. The application cannot view, read, or modify other files or folders in the user’s Google Drive.

User Control

Users maintain full control over their data and may:

Delete backup files directly from Google Drive at any time
Revoke the application’s Google Drive access through their Google Account settings
